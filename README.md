## Open-source tools for AI coding, Windows and trading

I'm a full stack developer working with the PERN stack (PostgreSQL, Express, React and Node.js), and I build small, practical open-source tools: an AI coding agent for the terminal, an alert forwarder from MetaTrader 5 to Telegram, and a dark theme for Microsoft RDCMan. All three are free to use, and the code is short enough to read.

### [Sigil Code](https://github.com/X-AlphaCoder-X/sigil-code): AI coding agent for your terminal

An open-source coding agent written in plain Python. It works with any OpenAI-compatible model, including OpenAI, Anthropic Claude, Google Gemini, DeepSeek, OpenRouter and local models on Ollama, vLLM, LM Studio and llama.cpp. It's built to keep small and local models on track and runs natively on Windows, Linux and macOS. It has sub-agents, MCP servers, hooks and checkpoints with /rewind.

### [MT5 Alert to Telegram](https://github.com/X-AlphaCoder-X/mt5-alert-to-telegram): forward MetaTrader 5 alerts to Telegram

Sends MetaTrader 5 `Alert()` messages to your Telegram chats, usually within a fraction of a second, from any indicator or Expert Advisor without changing its code. It works with compiled `.ex5` files too. It can read the Experts log as a safety net for alerts the popup missed, and it handles several terminals and chats at once. Python, Windows only.

### [RDCMan Dark Theme](https://github.com/X-AlphaCoder-X/rdcman-dark-theme): dark mode for Remote Desktop Connection Manager

Dark mode and custom colour themes for Microsoft's Remote Desktop Connection Manager (RDCMan) from Sysinternals. It recolours the server list, menus, title bar, dialogs and scrollbars without touching your remote sessions. It's one PowerShell script with nothing to install.

### Tech I work with

Python, PowerShell, JavaScript and TypeScript, PostgreSQL, Express, React, Node.js, C++, C# and LLM APIs.

On Windows I work in C++ with the Win32 API, including how Windows identifies hardware like device instance IDs, hardware IDs and device enumeration through SetupAPI.

I also build messaging automations and bots in Node.js and TypeScript, such as a bridge that forwards messages between Telegram and WhatsApp.
